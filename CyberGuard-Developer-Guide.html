CyberGuard: Developer & Architecture Guide

Target Audience: Hackathon developers with basic HTML, CSS, and JavaScript knowledge.

This guide translates how we built the modern CyberGuard dashboard into simple, easy-to-understand concepts so you can build, modify, and expand upon it yourself.

The Big Picture: Instead of writing dozens of separate HTML files, we used a framework called Next.js (React). React lets us create reusable "custom HTML tags" (called Components). For styling, instead of a separate CSS file, we used Tailwind CSS, which lets us style elements directly inside our HTML using simple keywords.

1. The Technology Stack

  • React.js: The core engine. It lets us write JavaScript that returns HTML.
  • Next.js (App Router): A framework built on top of React. It handles our folders and creates website pages automatically (e.g., putting a file in src/app/threats automatically creates the /threats website link).
  • Tailwind CSS: A styling tool. Instead of writing style="background-color: red;", you just type class="bg-red-500" in your HTML.
  • Lucide React: A library of free, professional SVG icons used for the dashboard (like the shield, globe, and alert icons).

2. Step-by-Step Procedure: How We Built It

Step 1: Project Setup

To start a project like this from scratch, a developer opens their terminal and runs:

npx create-next-app@latest cyberguard

This automatically downloads Next.js, sets up Tailwind CSS, and creates the folder structure. No manual configuration of Webpack or servers is needed.

Step 2: Building Reusable "Components" (Like Lego Blocks)

In standard HTML, if you want 10 buttons, you write the HTML for a button 10 times. If you want to change the color, you change it 10 times. In React, we created a single Button.tsx file.

Now, anywhere in the app, we can just type <Button>Click Me</Button>. We did this for Cards, Badges, and the Risk Indicator circle.

Step 3: The Global Layout (The "Shell")

We created a Sidebar and a Header. Next.js has a special file called layout.tsx. Anything you put in this file wraps around every single page on the website.

// Simplified layout.tsx
export default function Layout({ children }) {
  return (
    <div class="flex">
      <Sidebar />
      <div class="content">
        <Header />
        {children} <!-- The specific page content goes here -->
      </div>
    </div>
  )
}

Step 4: React "State" (Making it Interactive)

In vanilla JavaScript, to change text when a button is clicked, you have to use document.getElementById() and manually update the DOM. React does this automatically using something called State.

For the Analyzers (URL, Message, Media), we used a State variable called status. It can be one of three words: "idle", "analyzing", or "complete".

  • If status is idle: We show the HTML for the input box.
  • If status is analyzing: We hide the input box and show the HTML for a spinning loader.
  • If status is complete: We hide the loader and show the final Risk Score HTML.

Step 5: Simulating AI Analysis (The Hackathon Trick)

Since we don't have a real multi-million dollar AI backend, we simulated it for the demo. When the user clicks "Analyze", we trigger a JavaScript setInterval timer.

// How the scanning animation works
let currentStep = 0;
const interval = setInterval(() => {
  currentStep++;
  if (currentStep < 5) {
    updateLoadingText(currentStep); // Changes text to "Scanning metadata..."
  } else {
    clearInterval(interval);
    setStatus("complete"); // Shows the final results!
  }
}, 1500); // Waits 1.5 seconds per step

Step 6: The "Print to PDF" Report Trick

For Phase 9 (Reports), we needed a way to export PDFs. Generating PDFs via code is very complex and heavy. Instead, we used a clever CSS trick.

We built a normal webpage, but we used Tailwind's print: classes. For example, print:hidden hides the sidebar when printing. print:bg-white forces the dark-mode dashboard to turn white for the printer. We then tied a button to the simple JavaScript command: window.print().

3. How to Modify This Code

If your team wants to change the website for the presentation:

  • To change the Dashboard numbers: Open src/app/page.tsx. Look for the const METRICS = [...] array at the top and change the text.
  • To change the Colors: Open src/app/globals.css. You will see CSS variables (like --primary). Change the HEX codes there.
  • To add a new Sidebar link: Open src/components/layout/sidebar.tsx and add a new item to the navigation list.
